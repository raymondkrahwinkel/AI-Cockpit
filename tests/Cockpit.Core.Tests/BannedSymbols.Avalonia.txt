N:Avalonia.Threading;AC-577: Cockpit.Core.Tests does not set up an Avalonia application, so Dispatcher.UIThread binds to whichever thread touches it first — under the parallel xUnit run that is a coin flip, producing either a false-green test (CheckAccess() wins, the inline branch runs and proves nothing) or an eighteen-minute CI hang (the call lands on a dispatcher nobody pumps). Tests that need a real, pumped UI-thread dispatcher belong in Cockpit.App.ViewTests, which sets up a headless Avalonia application. See CONTRIBUTING.md.

# Administrator terminal (Windows)

Use **New administrator terminal (separate window)** from the `+ New` menu when a shell command needs administrator rights. Windows shows its normal UAC prompt. If it is declined, Cockpit starts nothing.

This is deliberately not a terminal pane. `ShellExecuteEx` with `runas` cannot attach the elevated process to Cockpit's ConPTY, so the window is visibly separate and Cockpit cannot read its transcript, show a statusline, list it as a session, or close it.

A session gets elevation through exactly one route (AC-1335): the `run_elevated` tool on the `cockpit-session` MCP server, which runs one PowerShell command as administrator. Every call shows the operator a consent card with the exact command line, the working directory and the agent's stated reason; only after approval does Cockpit start `powershell.exe -NoProfile -NonInteractive` through the same `runas` point as the administrator terminal, and Windows shows its UAC prompt. The command's output comes back to the tool through a file in `%TEMP%`; the decision and the command line land in the consent audit trail. Nothing is remembered and the assistant's consent bypass does not apply — one card and one prompt per call. There is still no elevation in profile settings or session start requests, and no elevated shell: a session that wants an interactive administrator session still needs the operator's window above. What a session does with its own full shell is governed by Windows UAC as before: a `runas` or `Start-Process -Verb RunAs` attempt shows the normal Windows prompt, which Cockpit neither removes nor bypasses — but that prompt names PowerShell, not the command, which is why the tool exists. Broader control of what an agent session may invoke belongs to the command-policy work around AC-1235, not this route.

The separate process also cannot join Cockpit's Windows Job Object. Measured on 2026-08-30: after UAC elevation, opening the target PID with `PROCESS_SET_QUOTA | PROCESS_TERMINATE` from the non-elevated Cockpit process failed with `ERROR_ACCESS_DENIED` (5), while `PROCESS_QUERY_LIMITED_INFORMATION` succeeded. Closing Cockpit therefore cannot reliably terminate this administrator window; close it from the window itself.

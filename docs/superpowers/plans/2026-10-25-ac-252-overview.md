# AC-252 Productivity Overview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Productivity Overzicht workspace with range selection, AC-1731 time totals, project/ticket/session breakdowns, usage and cost.

**Architecture:** Extend the existing plugin channel with one range snapshot that returns the host timeline, own entries, projects and `AttentionTime.Compute` result. A dedicated controller maps that snapshot into the existing shared chart controls and a code-built Avalonia workspace matching mockup v3.

**Tech Stack:** .NET 10, Avalonia 12, Cockpit plugin abstractions, xUnit headless view journey

**Spec:** `docs/superpowers/specs/2026-10-25-ac-252-overview-design.md`

## Global Constraints

- Code and labels follow AC-252; visible labels, heading and colors follow `Designs/productivity/screens-v3/08-overzicht.png`.
- Reuse `AttentionTime.Compute`, `ICockpitTimelineReader`, `GetProjectsAsync` and the shared chart controls.
- Add zero test methods; extend only `ProductivityHoursJourneyTests.OperatorRecordsTimeUsesStopwatchAndNavigatesDays`.
- No `!`, braces always, English code, comments at most three lines, no TODO without a ticket.
- Every plugin change bumps `plugins-dev/Cockpit.Plugin.Productivity/plugin.json`.

## Review Focus

- An inclusive one-day custom range must exclude the rest of the workweek.
- Overlapping own entries and measured attention must still count once through `AttentionTime.Compute`.
- Agent-without-you must alter only the chosen total and matching project segments.
- Tokens with no reported price must render `geen prijs`, not `$0`.
- Raw timeline rows and older day aggregates must not be counted twice.

# AC-1681 Discord DM-only Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restrict Discord assistant traffic to direct messages with one linked owner and migrate legacy channel or broad-audience settings without silent loss.

**Architecture:** `AssistantChannelAccess` is the fail-closed host boundary. `AssistantChannelStorage` owns the one-time data migration and persistent notice; Discord consumes that shared migration before reconnecting and otherwise keeps only its DM route.

**Tech Stack:** .NET 10, xUnit, Avalonia, Discord.NET

**Spec:** YouTrack AC-1681 and parent AC-1674 sections 2–5, including the two decisions in the 2026-10-25 comment.

## Global Constraints

- Only `SingleUser` with exactly one id may pass `AssistantChannelAccess.IsAllowed`.
- Preserve `ForUsers`, `ForEveryone`, and enum values for binary compatibility; mark the two factories obsolete.
- Legacy `SpecificUsers` with multiple ids and `Everyone` become unlinked and the notice names prior ids.
- UI copy is exactly `Link your own account to receive messages.` and all outbound Discord traffic is DM-only.
- Discord becomes 2.0.0; `abstractionsVersion` stays 3; Abstractions gets a minor version; `minHostVersion` matches this host release.
- Add no more than two test methods; both are layer 2, authorization.

## Review Focus

- A restored broad audience must fail closed before migration; covered by Task 1's existing access test update.
- Re-running migration must not overwrite or repeat its notice; covered by Task 1's migration theory.
- A channel message from the linked owner must still be refused and logged without content; covered by Task 2's filter and bridge assertions.
- Empty linked-user storage must open no connection or target; covered by Task 3's staging test and existing target behavior.
- Saving settings must clear the migration notice while leaving token and verbosity usable; covered by Task 3's staging test.
